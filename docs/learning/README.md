# 학습 기록

실제 학습 진행에 맞춰 작성한다. 주제를 학습하고 개발자가 직접 구현한 뒤에 해당 파일을 만든다 (미리 채우지 않는다).

## 1. 주제별 진행 상황

상태: `미시작` → `학습 중` → `구현 완료` → `학습 완료`

구현 완료는 개발자가 코드를 직접 작성하고 동작을 확인한 상태이고, 학습 완료는 원리를 자기 말로 설명할 수 있는 상태다.

## 2. 기록 양식

파일명: `주제-번호.md` (예: `01-project-init.md`)

1. 학습 목표와 요구사항 ID
2. 핵심 개념 (비유 포함, 전문 용어는 풀어서)
3. 사용한 공식 문서 URL과 적용 버전
4. 개발자가 직접 작성한 파일과 핵심 코드 요약
5. 실행 흐름 (요청부터 응답까지)
6. 코드 리뷰 결과와 수정 내용
7. 트러블슈팅 (문제 / 재현 조건 / 원인 / 해결 / 검증)
8. 실제 테스트 결과 (실행하지 않았으면 "미실행")
9. 이해도 확인 질문 2~3개와 개발자의 답변
10. 재학습이 필요한 개념
