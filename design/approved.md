# 디자인 승인 상태

화면별 디자인 승인 상태를 관리합니다. 상태가 `승인`인 화면만 UI로 구현할 수 있습니다.

상태 값: `시안 없음` → `시안 검토 중` → `승인` / `수정 요청`

## 3. 참고 자료 (구현 기준 아님)

`design/references/notion-concept/`의 SVG는 Notion 개념 설계 이미지이며 UI 구현 기준으로 쓰지 않습니다.

## 4. 브랜드 컨셉 (승인: 2026-11-27, ChatGPT에서 개발자가 승인)

화면별 구현 승인이 아니라 **방향 승인**이다. 실제 시안·이미지 원본은 ChatGPT에서 제작 후 전달 예정이며, 전달 전에는 화면 상태를 `승인`으로 바꾸지 않는다.

| 항목 | 값 |
| --- | --- |
| 브랜드명 / 슬로건 | KIX / GET YOUR NEXT KICKS. |
| 컨셉 | 미니멀, 스트릿 패션, 프리미엄 스니커즈 커머스 |
| Primary / Background / Surface | #111111 / #FFFFFF / #F4F4F4 |
| Accent / Error | #D5FA38 / #EF4444 |
| 타이포 | Pretendard 우선 (웹폰트 로딩 방식은 구현 단계에서 결정, 미확인) |
| 로고 | 볼드 이탤릭 워드마크 (파일 미전달) |
| 상품 카드 그리드 | PC 4열 / 태블릿 3열 / 모바일 2열 (브레이크포인트 px 값은 시안에서 확정) |
| 주요 구매 버튼 | 라임 배경 + 검은 텍스트 |

`design/tokens/tokens.json`에는 색상 5개가 이미 같은 값으로 들어 있고 typography·spacing·radius는 비어 있다. ChatGPT가 토큰을 전달하면 개발자가 병합한다.

## 5. 승인 기록

- 2026-11-27: 브랜드 컨셉 방향 승인 (4장). 화면별 시안은 모두 "시안 없음" 유지.

승인할 때마다 날짜, 화면, 파일 경로, 수정 요청 내용을 여기에 추가합니다.
