# design/

| 경로 | 용도 |
| --- | --- |
| `brand/` | 로고·워드마크 원본 |
| `wireframes/` | 화면 와이어프레임·고해상도 UI 시안 원본 |
| `banners/` | 배너 원본 |
| `products/` | 상품 이미지 원본 (파일마다 출처·라이선스 기록) |
| `tokens/` | 디자인 토큰 (`tokens.json`) |
| `references/notion-concept/` | Notion 개념 SVG (참고용, 구현 기준 아님) |
| `approved.md` | 화면별 승인 상태 |

구현용으로 내보낸 파일은 `frontend/`에 두고, 원본은 이 폴더에 보관합니다.
