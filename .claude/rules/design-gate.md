# 디자인 승인 게이트

1. 화면 구현을 안내하기 전에 `design/approved.md`에서 해당 화면의 상태를 확인한다.
2. 상태가 `승인`이 아니면 구현 안내를 시작하지 않고 시안 확인을 요청한다. 프론트엔드 초기 환경 구성은 시안 없이도 가능하다.
3. `design/references/notion-concept/`의 SVG는 개념 참고용이며 구현 기준이 아니다.
4. 디자인 파일은 원본 / 승인본 / 구현용 이미지 / 디자인 토큰으로 구분한다. 시안은 ChatGPT에서 별도로 제작한다.
5. 승인 상태와 적용 규칙은 `design/approved.md`에 기록한다 (Claude가 직접 갱신 가능).
6. 디자인 파일 배치와 React 적용은 개발자가 직접 한다. Claude는 방법을 안내하고 리뷰한다.
7. 상품 이미지는 출처와 라이선스를 기록한다. 출처를 모르는 이미지는 쓰지 않는다.
8. 색상: 포인트 #D5FA38, 기본 #111111 / #FFFFFF / #F4F4F4, 기능성 #EF4444(오류·위험). 라임은 강조 배경 + 검은 텍스트 조합을 우선하고 흰 배경 위 작은 글자색으로 쓰지 않는다.
9. 구현 후에는 브라우저 캡처를 승인된 시안과 비교한다.
