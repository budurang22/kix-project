# /wrap-up

세션 종료 전에 아래 순서로 진행한다. 이 스킬은 `docs/`와 `.claude/`만 수정한다. 소스 코드는 읽기만 하고, commit·push는 하지 않는다. 비밀값은 어디에도 적지 않는다.

1. `git status -sb`, `git diff --stat`으로 변경 파일을 확인하고, 개발자가 직접 작성한 파일과 Claude가 수정한 문서를 구분한다.
2. 실행한 테스트와 **실제 결과**를 정리한다. 실행하지 않은 것은 "미실행", 목표일 뿐인 것은 "목표"로 적는다.
3. `docs/session-log.md` 맨 아래에 세션 항목을 추가한다.
   - 날짜, 목표, 완료된 기능, 개발자가 직접 작성한 파일, 학습한 기술·개념, 코드 리뷰 결과, 트러블슈팅, 실제 테스트 결과, 미완료 사항, 다음 작업
4. `docs/progress.md`를 갱신한다. **구현 완료**와 **학습 완료**를 구분해서 적는다.
5. 학습한 개념이 있으면 `docs/learning/`에 기록하고, 핵심 기능이 끝났다면 면접 확인 질문 2~3개를 남긴다. 이해하지 못한 개념은 "재학습 필요"로 표시한다.
6. 설계가 바뀌었으면 `docs/decisions.md`, 공식 문서를 새로 확인했으면 `docs/references.md`를 갱신했는지 확인한다.
7. 개발자에게 요약을 보고하고, 다음에 할 Git 작업이 있으면 명령어와 이유를 안내한다 (실행은 개발자).
